## Cleanup checklist

### GitHub (manual)

- [ ] Enable secret scanning + push protection
- [ ] Branch protection on `master` (require CI checks)
- [ ] Pin latest release on GitHub Releases page
- [ ] Close/delete stale issues referencing v0.1.x benchmarks

### Repo files (safe to remove when confirmed unused)

| Path | Notes |
|------|--------|
| `docs/archive/*` | Delete entire folder if you no longer need review history |
| `docs/images/.sync-*`, `docs/images/*-frames/` | Regenerated by scripts; gitignored patterns in `.gitignore` |
| `scratch/`, `.tmp/`, `test.md` | Local scratch — gitignored |
| Duplicate path `docs\product-roadmap.md` vs `docs/product-roadmap.md` | Same file on Windows; one inode |
